## Projects

**BioTrak** *(Production — Live)*
Stack: React, FastAPI, Python, PostgreSQL, Redis, Celery, ReportLab, Docker

Production DNA sequence analysis platform offering 10 scientific analysis modules in a single browser-based interface. Implements custom pure-Python algorithms for base composition, ORF detection across all six reading frames, nearest-neighbour primer design (SantaLucia 1998), Smith-Waterman local alignment, restriction enzyme mapping (40 enzymes), GC skew analysis, RSCU codon usage scoring, and protein physicochemical property calculation. Features async NCBI BLAST integration via Celery workers, AI-powered sequence interpretation via the Anthropic Claude API, JWT-based authentication with role-based access control, and a ReportLab PDF report generator. Deployed on Render (backend) and Vercel (frontend) using Neon PostgreSQL and Upstash Redis on free-tier infrastructure.

*GitHub: github.com/modd3/BioTrak*
